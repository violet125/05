# 听见行动 · 扣子 Agent 完整应用源码

面向视障与低视力用户的本地网页应用。网页负责输入、朗读与读屏友好的呈现；Node.js 后端负责附件检查、CSV计算、会话隔离和扣子API调用；在扣子中配置的智能体负责图片理解、邮件整理、协议解释与写作。

这是可运行的完整应用代码，不是扣子工作流导入文件，也不包含账号凭据。必须先在扣子创建并发布自己的智能体，才能得到真实AI回答。无需安装第三方 npm 依赖。

## 一、准备扣子智能体

1. 在扣子创建对话型智能体，名称填写“听见行动”。
2. 把 `agent-prompt.md` 全文复制到其人设／系统指令配置中。这份提示词运行在扣子端，本地后端不会自动替你修改云端智能体。
3. 选择你账号中支持图片输入的模型，验证可以理解上传图片。仅使用文本模型时，图片功能不能正常工作。
4. 按账号可用的发布流程，发布到支持API访问的渠道，取得 Bot ID。
5. 创建具备该智能体访问、聊天及文件上传所需权限的API凭据。具体授权入口与权限名称以扣子当前控制台为准。
6. 第一版不需要邮件发送、付款或其他外部写入工具。邮件由用户粘贴，表格由本地解析。

API参考入口：

- https://www.coze.cn/open/docs/developer_guides/chat_v3
- https://www.coze.cn/open/docs/developer_guides/retrieve_chat
- https://www.coze.cn/open/docs/developer_guides/list_chat_messages
- https://www.coze.cn/open/docs/developer_guides/upload_files

本次环境未能成功访问官方文档；代码按扣子V3接口流程实现，并通过模拟服务测试。实际账号的模型、图片输入、授权和发布配置仍需联调，不宣称已经连接你的扣子账号。

## 二、运行

安装 Node.js 22.9 或更高版本（建议使用当前受支持的LTS版本）。

Windows：解压后双击 `start.cmd`。首次会创建并打开 `.env`；填写后保存，再运行一次启动脚本。

也可在项目文件夹内使用 PowerShell：

```powershell
Copy-Item .env.example .env
notepad .env
node --env-file-if-exists=.env server.mjs
```

`.env` 需要填写：

```dotenv
COZE_API_TOKEN=你的扣子凭据
COZE_BOT_ID=你的智能体ID
COZE_BASE_URL=https://api.coze.cn
PORT=3000
```

打开 http://127.0.0.1:3000 。服务只监听本机。密钥只保留在后端，切勿把 `.env` 提交到仓库或发给他人。

使用Coze国际站时，可将域名改为 `https://api.coze.com`，但账号、凭据和Bot必须属于对应站点。

未填凭据时页面仍可打开，发送问题会提示“尚未配置扣子”，不会生成假回答。配置检测只检查字段是否存在，真实权限由首次API请求验证。

## 三、可以做什么

- **图片**：上传PNG/JPEG，询问菜单、账单、设备接口或场景。最多6MB；依赖扣子端视觉模型与图片访问能力。
- **邮件与协议**：粘贴文字或上传UTF-8 TXT/MD，提取待办、期限和关键条款。文本最多24000字符且不超过150KB。
- **筹款CSV**：上传UTF-8 CSV，最多150KB、5000条数据。服务器用整数分精确汇总金额，分币种计算并标记无效金额、负数和重复编号。
- **语音输入**：使用浏览器SpeechRecognition（浏览器支持时），识别结果填入输入框，核对后手动发送。
- **语音输出**：使用浏览器SpeechSynthesis，可朗读最新回答、停止朗读或选择自动朗读。
- **多轮对话**：浏览器获得HttpOnly会话Cookie，后端持有扣子conversation_id；不同浏览器会话不共用对话。
- **辅助办公**：通过扣子生成邮件草稿、发言稿、演示文稿提纲或无障碍网站建议；不直接生成PPTX，不自动发布网站。

CSV支持金额列名：`实收金额`、`金额`、`amount`、`received_amount`；币种列名：`币种`或`currency`；编号列名：`编号`或`id`。多个可识别金额列同时存在时取最先出现的一列，计算报告会显示选中的列名；如需别的口径，先导出对应列。

金额只接受最多两位小数的纯数字。空值、货币符号、千分位和更多小数位会被列为无效，不会静默转换。重复编号不会自动去重。缺少币种时标记“未注明币种”，不能据此假定记录币种一致。

完整CSV在本地解析；发送给扣子的是全表汇总与前20条样本。智能体不能利用样本回答未计算的全表统计问题。需要更复杂分析时，应扩展计算函数或接入可靠的数据工具。

示例：上传 `sample-donations.csv` 并问“按币种汇总实收金额并指出待核查项目”。人民币总额应为260.00，美元20.00，另有1条无效金额。

## 五、测试

```powershell
node --test
```

自动化测试覆盖CSV精确计算与格式校验、扣子请求流程、上传图片参数、授权失败、超时、页面访问、会话隔离与重置、跨站请求阻止。测试使用模拟扣子服务，不调用收费接口。

上线前人工验证：

1. 配置真实Bot后发送普通问题，接着追问，确认上下文可延续。
2. 上传清晰菜单，再上传模糊图片，确认不编造价格和文字。
3. 上传示例CSV，核对金额和异常记录。
4. 使用Tab键完成操作；结合实际读屏软件检验焦点、标签和回答阅读顺序。
5. 在目标浏览器验证中文听写、朗读、停止按钮及麦克风拒绝权限后的表现。

浏览器语音与真实读屏软件尚未在本次环境中完成实机验收。语音识别依赖浏览器、系统、网络和语言支持；不支持时仍可用文本输入及系统读屏。

## 六、数据与部署边界

- 本地不将对话或附件写入磁盘；会话存于进程内存，闲置30分钟失效，重启也会失效。
- 扣子调用开启云端对话历史保存；图片上传与文字内容可能由扣子保存，受其服务设置与政策约束。本地“新对话”不删除云端历史。
- 浏览器语音可能调用其厂商的在线识别或合成服务，不能承诺完全离线。
- 本地服务默认没有账号系统，禁止直接开放到公网；公网部署需增加登录、HTTPS、访问控制和限流。
- 本应用没有邮件发送、付款、签约、删除邮件、实时摄像头或道路导航执行能力。不要在扣子端随意添加会自动执行这些动作的插件。
- 不支持PDF、DOCX或XLSX直接解析；可转换为文本或CSV后使用。输出网页代码或演示文稿提纲不代表已生成完整网站或PPT文件。
- AI对视觉和协议内容可能判断错误；道路通行等高风险判断必须依据可靠现场信息。

## 七、常见问题

“尚未配置扣子”：检查 `.env` 文件名，填写两个必填字段，重启服务。

“凭据无效或权限不足”：确认API凭据未过期，Bot已发布到API渠道，文件上传和聊天权限已授予，且域名与账号站点一致。

图片无回答：先在扣子预览中验证视觉模型，再检查文件上传接口权限和图片格式。

“需要客户端工具操作”：该Bot启用了需要客户端执行的工具；本版不执行远程要求的任意操作，需在扣子端更换为已配置的服务端能力。

等待超时：默认整个调用期限约90秒；可能存在云端已收到请求但本地没拿到结果的情况。不会自动重试，避免重复发起调用。

端口被占用：在 `.env` 修改 `PORT`，重启并打开相应地址。
